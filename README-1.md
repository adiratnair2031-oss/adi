**Aim:** Use AI to prepare professional documentation.

This project contains documentation for installing Python, drafted with AI assistance and then reviewed by the student. It is organised into short, linked sections.

## How to Use This Documentation

1. Start with **[Introduction.md](Introduction.md)** to understand the purpose of this guide and check the software requirements.
2. Follow **[Installation.md](Installation.md)** for installation steps (Windows, macOS, Linux), verification steps and troubleshooting.
3. Check **[FAQ.md](FAQ.md)** for answers to common questions and the conclusion.
4. See the **Images/** folder for the screenshots referenced in Installation.md.
