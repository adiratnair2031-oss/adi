# Introduction

## About This Document

This documentation provides a complete, step-by-step guide for installing Python on your computer. Python is a high-level, general-purpose programming language known for its readability, simplicity, and versatility. It is widely used in web development, data science, automation, artificial intelligence, scripting, and many other domains.

Whether you are a beginner setting up Python for the first time or an experienced user reinstalling it on a new machine, this guide walks you through everything you need — from checking software requirements to verifying a successful installation.

## Who This Guide Is For

- Students and beginners learning to program
- Developers setting up a new development environment
- IT administrators deploying Python across multiple machines
- Anyone who needs a clean, working Python installation

## What You Will Learn

1. The software and hardware requirements needed before installing Python
2. How to download and install Python on Windows, macOS, and Linux
3. How to verify that the installation was successful
4. How to troubleshoot common installation issues
5. Answers to frequently asked questions about Python installation

## Software Requirements

Before installing Python, ensure your system meets the following requirements.

### Operating System Support

| Operating System | Minimum Version |
|---|---|
| Windows | Windows 10 or later (64-bit recommended) |
| macOS | macOS 11 (Big Sur) or later |
| Linux | Any modern distribution (Ubuntu 20.04+, Fedora, Debian, etc.) |

### Hardware Requirements

- **Processor:** 1 GHz or faster
- **RAM:** Minimum 2 GB (4 GB or more recommended)
- **Disk Space:** At least 100 MB of free space for the base installation

### Other Requirements

- An active internet connection (to download the installer and packages)
- Administrator/root access (to install software system-wide)
- A web browser (to download the installer from python.org)
