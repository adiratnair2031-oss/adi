# Laboratory Report: Python Student Marks and Grade Calculator

## 1. Abstract

The experiment involved developing and executing a Python program to calculate a student's average mark and assign a corresponding grade. The program used three functions to calculate the arithmetic mean, determine the grade based on predefined thresholds, and display the result. For the test case, marks of 85, 78, and 92 produced an average of 85.0 and a grade of B. The experiment demonstrated how functions can divide a programming task into smaller components. The output was checked against the implemented grading rules. The program was then documented with docstrings, type hints and a README, and the documented version was shown to produce the same output as the original.

## 2. Objective

1. To calculate the arithmetic mean of three subject marks.
2. To assign a grade according to predefined average-mark thresholds.
3. To display the student's name, average, and grade.
4. To understand the use of functions for dividing a program into manageable tasks.
5. To document the Python functions using docstrings and type hints, and to check AI-generated documentation for accuracy.

## 4. Results

| Student | Mark 1 | Mark 2 | Mark 3 | Average | Grade |
|---|---:|---:|---:|---:|---|
| Anu | 85 | 78 | 92 | 85.0 | B |

The average is calculated as (85 + 78 + 92) / 3 = 255 / 3 = 85.0.

Since 85.0 is at least 75 and less than 90, the program assigns grade B. The documented version printed the same name, average and grade as the original program.

## 5. Conclusion

The experiment demonstrated the use of Python functions to calculate an average, assign a grade, and display a result. For the test case involving marks of 85, 78, and 92, the program calculated an average of 85.0 and assigned grade B according to the implemented thresholds. The objective was achieved. The exercise also showed how function docstrings and type hints improve readability, and how AI-generated documentation must be checked against the code. However, only one predefined test case was used, so additional tests would be needed to check boundary values (such as 90, 75 and 50) and other possible inputs.
